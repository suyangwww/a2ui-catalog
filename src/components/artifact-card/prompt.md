Packages a long report, itinerary, or spec as a clean preview card that opens in a side panel. Use ArtifactCard whenever a deliverable is longer than ~10 lines so the chat stays tidy.
Platform behavior: Opens in a split Canvas panel on Desktop, a spacious dialog on iPad, and a slide-up bottom sheet on iPhone.

Props: `title`, `subtitle`, `kind`, `version`, `preview`, `child`, `action`, `weight`
