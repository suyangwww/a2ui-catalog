Arranges cards into a clean multi-column grid that adapts to screen width. Use Grid to display 2 to 6 summary metrics, option cards, or highlights side by side.
Platform behavior: Shows 3 columns on Desktop, 2 columns on iPad when minItemWidth is set, and stacks into 1 clean column on iPhone.

Props: `children`, `columns`, `minItemWidth`, `gap`, `weight`
